UI 测试（界面视觉测试）
一、定义
UI 测试即界面视觉测试，检查页面视觉、布局、样式、交互展示是否符合 UI 设计稿、产品规范，只关注页面好不好看、排版有没有错乱、展示是否统一，不侧重业务逻辑。
二、核心测试范围
1. 整体布局对齐
页面控件对齐：输入框、按钮、表格、弹窗统一左对齐 / 居中 / 右对齐
边距间距：组件上下左右留白、行间距、列间距和设计稿一致
自适应布局：
网页：缩放浏览器窗口、最大化 / 最小化无错位、无横向滚动条
APP：不同尺寸手机、平板、横竖屏切换，元素不挤压、不截断
2. 文字样式校验
字体、字号、字重（粗体 / 常规）统一
文字颜色、提示色、报错色、标题色区分正确
文字不截断、不重叠、不超出输入框 / 表格单元格
中英文、长文本展示完整，无乱码
3. 控件样式统一
按钮、输入框、下拉框、单选框、复选框、图标、标签：
常规态、hover 悬浮态、点击态、禁用态样式区分正确
圆角、阴影、边框粗细和设计稿统一
图标大小、配色一致，无模糊、拉伸变形
4. 表格与列表 UI
表头固定、行列宽度分配合理
隔行底色、选中行高亮展示正常
分页控件位置、样式统一，页码无重叠
5. 弹窗、浮层
弹窗居中展示，遮罩层覆盖整个页面
弹窗内按钮、文字排版整齐
点击空白处 / 关闭按钮可正常关闭浮层，不会穿透操作底层页面
6. 特殊状态展示
空数据页面、加载中、无权限、报错页面、404 页面：
占位图、提示文案、按钮位置符合规范
加载动画不卡顿、样式统一
7. 多场景细节
弹窗多层叠加不重叠错乱
滚动页面时标题 / 表头吸顶正常
按钮文字居中，不会偏上偏下
不同分辨率、缩放比例（100%/125%/150%）无排版崩坏
三、UI 测试和功能测试区别
UI 测试：看视觉、样式、排版、美观度
功能测试：看业务逻辑、操作能否正常生效
举例：
点击登录按钮能跳转登录页 = 功能正常
登录按钮大小、颜色、文字位置和设计图不一样 = UI 缺陷
四、常见 UI 缺陷举例
两个相同按钮，一个圆角大、一个圆角小
弹窗文字超出框外，被截断
缩小浏览器后表格挤在一起，文字重叠
报错文字红色和规范不一致
图标拉伸模糊、位置偏移
空列表无空状态提示，空白一片

## 检查字段
- 1、测试页面必须包含用户信息标题检查
- 2、测试页面必须包含查询字段的检查：用户名、昵称、角色类型以及输入框等 
- 3、测试页面必须包含查询按钮的检查：新增用户、查询、重置，
- 4、测试页面必须包含列表字段的检查：用户名、昵称、部门名称、角色类型、角色名称、链账户、状态、创建时间、操作列



## 操作流程
- 1、测试 新增用户：点击新增用户按钮，填写用户信息，包括用户名为输入框、昵称为输入框、部门名称为输入框、 角色类型为下拉框，包含管理员和普通业务员两个选项、角色名称为下拉框，包含内置管理员和内置普通业务员两个选项，角色类型选择管理员时，角色名字只有内置管理员一个选项，角色类型选择普通业务员时，角色名字只有内置普通业务员一个选项，点击确认按钮，检查用户是否新增成功
- 2、测试查询用户：输入查询条件，点击查询按钮，检查查询结果是否符合预期，查询包含用户名、昵称、角色类型查询
- 3、测试查询重置查询：点击重置按钮，检查查询字段是否清空，显示所有用户信息
- 4、测试编辑用户：点击列表中的编辑按钮，填写用户信息，只能更新用户名称，角色类型，角色名称，点击确认按钮，检查用户信息是否更新成功
- 5、测试禁用用户：点击列表中的禁用按钮，检查用户状态是否更新为禁用
- 6、测试启用用户：点击列表中的启用按钮，检查用户状态是否更新为启用

## 添加用户流程字段校验规则
- 1、测试添加用户弹出框用户字段必须包含用户信息用户名称，昵称，部门名称，角色类型，角色名称；字段限制检查：用户名称不能为空，昵称不能为空，部门名称可以为空，角色类型不能为空，角色名称不能为空；用户名，昵称，部门名称的长度不能超过50个字符；角色类型选择管理员时，角色名字只有内置管理员一个选项，角色类型选择普通业务员时，角色名字只有内置普通业务员一个选项；
- 2、测试编辑用户弹出框用户字段必须包含用户信息，昵称，部门名称，角色类型，角色名称；字段限制检查：用户名称不能为空，昵称不能为空，部门名称可以为空，角色类型不能为空，角色名称不能为空；用户名，昵称，部门名称的长度不能超过50个字符；角色类型选择管理员时，角色名字只有内置管理员一个选项，角色类型选择普通业务员时，角色名字只有内置普通业务员一个选项；
- 3、测试添加的用户名必须以auto开头
